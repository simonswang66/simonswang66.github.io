🎨 Clawd-on-desk 主题工作流

以女儿照片为原型，通过即梦 AI 生成大头小身体角色形象，制作 Claude Code 桌面宠物动画主题

项目概览
这是一个 Claude Code 自定义动画主题的制作项目。核心思路：用一张女儿的真人照片作为面部参考，通过即梦 AI 的角色特征参考功能，生成一系列"大头小身体"比例的动画素材，最终集成为 Clawd-on-desk 桌面宠物主题。

核心工具

即梦图片生成 图片5.0 Pro（生参考图）→ 即梦视频生成 Seedance 2.0mini（参考图生视频）→ video2gif.py（转 GIF）→ Clawd-on-desk 集成

动画状态

共 16 个动画状态，覆盖 idle / thinking / working / attention / sleeping / sleep sequence / drag / roam 等全部场景

制作耗时

约半天：角色设定 30-60min + 核心状态 1-2h + 增强状态 30-60min + 后期处理 ~1h

关于 Clawd-on-desk
Clawd-on-desk 是一个开源的桌面宠物框架，通过 Hook 实时监听 Claude Code、Codex、Cursor 等 AI 编程助手的生命周期事件，自动切换桌面宠物的动画状态。支持 Windows / macOS / Linux，提供 12 种动画状态、权限气泡弹窗、多会话仪表盘、睡眠序列等特性，内置 3 套官方主题并支持自定义主题。

工作流（6 个阶段）
从原始照片到最终主题的完整制作流程。核心原则：脸 = 真实保留照片面部特征，身体/比例 = 头大身小。Prompt 中绝不出现"Q版""卡通""插画"等词汇，以防即梦生成卡通脸破坏面部真实感。
1

生成角色设定图

⏱ 30-60 min · 即梦图片生成 图片5.0 Pro · 1:1 方形 · 仅此一次

将女儿大头照上传即梦，勾选「角色特征」参考，面部参考强度 90-95。生成一张大头小身体比例（头身比约 1:1.5）的角色设定图。这是最关键的步骤——后续所有视频都以这张为唯一角色参考基准，必须反复生成直到满意。

💡 核心原则：脸 = 真实保留照片面部特征，身体/比例 = 头大身小。Prompt 中绝不出现"Q版""卡通""插画"等词汇。

2

逐个状态：参考图 → 视频 → GIF

⏱ 每状态 ~10-15 min · 即梦视频生成 Seedance 2.0mini · 1:1 720P 4s

每个动画状态都走同一条流水线：角色设定图作为角色参考 → Seedance 2.0mini 生成视频 → video2gif.py 转 GIF。Seedance 2.0mini 是即梦目前唯一支持真人人脸的视频生成模型。

每状态操作步骤：

  1. 即梦视频生成模式，上传角色设定图，勾选「角色特征」参考
  2. 输入视频 Prompt（描述动作），Seedance 2.0mini 输出 720P 4s MP4
  3. 运行 python3 video2gif.py input.mp4，自动 AI 抠图 → 缩放 512×512 → 合成循环 GIF
3

核心 5 状态（最小可用方案）

⏱ 1-2 h · 按阶段 2 流水线逐个生成

生成顺序：idle → thinking → working → attention → sleeping。这 5 个状态生成完就能让主题跑起来；error / notification / sweeping / carrying 等状态可先用 fallbackTo 回退到已有动画（仅 error / attention / notification / sweeping / carrying / sleeping 这 6 个状态支持）。

  • idle — 待机，眼睛左右转动
  • thinking — 思考中，歪头 → 托下巴沉思
  • working — 工作中，正面敲键盘，正对镜头
  • attention — 任务完成，开心笑 → 举手欢呼
  • sleeping — 60s 无操作，站立打瞌睡前后摇晃
4

增强 4 状态（第二轮制作）

⏱ 30-60 min · 同上流水线

核心状态跑通后制作，丰富主题表现力：

  • error — 工具调用失败，捂脸惊慌 + 感叹号
  • notification — 权限请求弹窗，举手示意"嘿，看这里"
  • waking — 鼠标移动唤醒，揉眼睛慢慢清醒
  • juggling — 多子代理并发，双手同时在两个键盘上打字
5

可选状态（锦上添花）

⏱ 按需 · 同上流水线
  • sweeping — 上下文压缩时，手持小扫帚扫地
  • carrying — 创建 worktree 时，双手抱纸箱搬运
  • yawning — 入睡序列第一步，站立打哈欠
  • dozing — 入睡序列第二步，站立打盹挣扎
  • collapsing — 入睡序列第三步，全身松软过渡到 sleeping
  • drag — 拖拽时，手抓红气球起飞
  • roam — 自由漫步，背着手模仿大人踱步
6

Clawd-on-desk 集成

⏱ 15 min · theme.json 配置 + 验证
  • 用脚手架创建主题目录：node scripts/create-theme.js my-daughter
  • 将 GIF 文件放入 assets/ 目录，编辑 theme.json 映射各状态到对应动画文件
  • 未完成的状态通过 fallbackTo 指向已有状态（如 error → attention），仅 error / attention / notification / sweeping / carrying / sleeping 支持；它是视觉兜底，逻辑状态（计时、命中框、流转）照常运行
  • 关闭眼球追踪和 Mini Mode（非 SVG 素材不支持）
  • 运行验证脚本确认配置正确：node scripts/validate-theme.js
theme.json 结构
主题目录下的核心配置文件，定义角色布局、动画映射、行为开关。

viewBox & layout

定义角色坐标空间和内容区域。viewBox 设定画布尺寸（100×100），contentBox 限制角色绘制范围，centerX/baselineY 控制居中与脚底对齐。

states

核心配置。将逻辑状态映射到 assets/ 下的动画文件。格式为 "状态名": ["文件名.gif"]，也支持对象格式 {"files": [...], "fallbackTo": "状态名"} 做素材缺失兜底——仅 error / attention / notification / sweeping / carrying / sleeping 这 6 个状态可写 fallbackTo，兜底不影响逻辑状态运行。

sleepSequence

控制入睡行为。"mode": "full" 启用完整入睡序列（yawning → dozing → collapsing → sleeping → waking）；"mode": "direct" 跳过序列直接切到 sleeping。

eyeTracking

眼球追踪开关。设为 false（当前项目非 SVG 素材不支持）。

miniMode

Mini Mode 精简布局。设为 false（素材量不够时关闭）。

动画预览
点击卡片查看 GIF 动画预览。使用左右箭头或键盘 ← → 切换状态。
