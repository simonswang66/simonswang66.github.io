# 女儿形象 Clawd-on-desk 主题 — 即梦生图全套 Prompt

## 核心原则

> **脸 = 真实保留照片面部特征，身体/比例 = 头大身小。**
>
> 即梦通过「角色特征参考」锁定面部，prompt 不再描述五官，只控制比例、动作、构图。
>
> **关键禁忌**：prompt 中绝不出现"Q版""卡通""插画""色块""线条"等词汇——这些词会触发即梦生成卡通脸，破坏面部真实感。

---

## 0. 前置操作指南

### 即梦关键设置（每张图都一样）

| 设置项 | 值 |
|---|---|
| 模型 | 图片生成 图片5.0 Pro |
| 画布比例 | 1:1 方形 |
| 参考图 | 上传角色设定图 |
| 参考类型 | 勾选「角色特征」 |
| 面部参考强度 | 90-95 |
| 主体参考强度 | 80-85 |

### 制作流程

```
女儿大头照 → 生成"角色设定图"（唯一参考基准）
    ↓
用设定图做参考 → 逐个状态生成（每个状态 2-3 张关键帧）
    ↓
批量去背景 → 合成 APNG/GIF
    ↓
配置 theme.json → 验证 → 启用
```

## 阶段 1：角色设定图（最关键的一张）

这是后续所有图的唯一参考基准。必须反复生成直到满意。

> **阶段 1 特殊说明**：这是从真实照片生成大头小身体比例角色设定的唯一一张图。后面的固定附加文本不适用于此阶段——因为此时还没有"角色设定图"作为参考。此阶段 prompt 需要额外定义身体比例和服装，后续状态不再重复。

### 即梦操作

| 设置项 | 值 |
|---|---|
| 模型 | 图片生成 图片5.0 Pro |
| 画布比例 | 1:1 方形 |
| 参考图 | 上传女儿大头照 |
| 参考类型 | 勾选「角色特征」或「人物写真」 |
| 面部参考强度 | 90-95 |

### Prompt

```
将参考照片中的小女孩做成大头小身体比例的形象。关键约束：

【面部】必须完全还原参考照片中的真实面部，包括五官形状、比例、神态，不做任何风格化、卡通化或改动。就是原图那张脸。唯一调整：面部亮度适当提高，肤色更明亮通透（原图偏暗）。

【身体】仅身体和四肢做缩小简化处理：头身比约1:1.5，头部占身高一半以上，身体小巧，四肢短圆。服装简洁可爱，浅色系。

构图：全身像，1:1方形画布，角色居中，脚底接触画面下边缘，头顶上方留少许空间。

```

## 阶段 5：后期处理

### 5.1 批量去背景

即梦生成的图带背景，必须去掉才能在桌面上透明显示。

| 工具 | 方式 | 成本 |
|---|---|---|
| **remove.bg** | 网页上传 / API 批量 | 免费额度有限，付费 |
| **macOS 自带** | Finder 右键 → 快速操作 → 移除背景 | 免费 |
| **PhotoRoom** | 网页版免费 | 有水印限制 |
| **Photoshop** | 录制动作 → 批处理 | 需安装 |

建议：数量不多（20-30 张），macOS 自带功能逐张处理即可。

### 5.2 视频转 GIF/APNG

即梦图生视频输出 4s mp4，用 `video2gif.py` 一键转换（AI 自动抠图，不依赖背景颜色）：

```bash
python3 video2gif.py input.mp4 [output.gif]
```

脚本流程：提取视频帧 → rembg AI 抠图（透明背景）→ 缩放到 512×512 → 合成循环 GIF。

如需 APNG 格式或自定义帧率/尺寸，可编辑脚本参数。

### 5.3 图片尺寸建议

- 生成分辨率：即梦选 1024×1024
- 最终素材：缩放到约 512×512 或 256×256（桌面宠物不需要太大）

```bash
# 批量缩放
for f in assets/*.apng; do
  ffmpeg -i "$f" -vf "scale=512:512:flags=lanczos" "assets_scaled/$(basename "$f")"
done
```

### 6.2 theme.json 最小配置

```json
{
  "schemaVersion": 1,
  "name": "女儿",
  "version": "1.0.0",
  "author": "",
  "description": "",
  "viewBox": { "x": 0, "y": 0, "width": 100, "height": 100 },
  "layout": {
    "contentBox": { "x": 10, "y": 10, "width": 80, "height": 80 },
    "centerX": 50,
    "baselineY": 95
  },
  "states": {
    "idle":         ["idle.apng"],
    "thinking":     ["thinking.apng"],
    "working":      ["working.apng"],
    "attention":    ["attention.apng"],
    "sleeping":     ["sleeping.apng"],
    "waking":       ["waking.apng"],
    "error":        { "fallbackTo": "attention" },
    "notification": { "fallbackTo": "attention" },
    "sweeping":     { "fallbackTo": "working" },
    "carrying":     { "fallbackTo": "working" },
    "juggling":     { "fallbackTo": "working" }
  },
  "sleepSequence": {
    "mode": "direct"
  },
  "eyeTracking": {
    "enabled": false
  },
  "miniMode": {
    "supported": false
  }
}
```

- `sleepSequence.mode: "direct"` — 直接进入 sleeping，跳过 yawning/dozing/collapsing 序列（因为还没做）
- `eyeTracking.enabled: false` — 关掉眼球追踪（非 SVG 素材不支持）
- `miniMode.supported: false` — 关掉 Mini Mode（素材量不够）
- 后续做出更多素材后逐步打开这些功能

关键状态映射说明：

| 逻辑状态 | 映射到 | 说明 |
|---|---|---|
| `error` | attention | 暂时没有 error 图，出错时显示开心图（行为上会知道出错了因为红色气泡） |
| `notification` | attention | 暂时用开心图代替通知 |
| `sweeping` | working | 压缩上下文时显示工作中 |
| `carrying` | working | 创建 worktree 时显示工作中 |
| `juggling` | working | 多子代理时显示工作中 |
