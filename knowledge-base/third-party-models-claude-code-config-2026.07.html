一、通用配置结构

所有第三方平台都通过修改 ~/.claude/settings.json（Windows 为 用户目录/.claude/settings.json）实现接入，核心字段：

{
  "env": {
    "ANTHROPIC_AUTH_TOKEN": "<你的 API Key>",
    "ANTHROPIC_BASE_URL": "<平台 Anthropic 兼容接口地址>",
    "ANTHROPIC_MODEL": "<默认模型>",
    "ANTHROPIC_DEFAULT_SONNET_MODEL": "<Sonnet 映射模型>",
    "ANTHROPIC_DEFAULT_OPUS_MODEL": "<Opus 映射模型>",
    "ANTHROPIC_DEFAULT_HAIKU_MODEL": "<Haiku 映射模型>"
  }
}

同时需要在 ~/.claude.json 中添加（跳过 onboarding 引导）：

{ "hasCompletedOnboarding": true }

  "env": {

    "ANTHROPIC_DEFAULT_OPUS_MODEL": "glm-5.2[1m]",

    "CLAUDE_CODE_DISABLE_NONESSENTIAL_TRAFFIC": 1,
    "API_TIMEOUT_MS": "3000000"
  }
}

一键安装脚本：

curl -O "https://cdn.bigmodel.cn/install/claude_code_env.sh" && bash ./claude_code_env.sh

2. DeepSeek

# Linux / Mac
export ANTHROPIC_BASE_URL=https://api.deepseek.com/anthropic
export ANTHROPIC_AUTH_TOKEN=<DeepSeek API Key>
export ANTHROPIC_MODEL=deepseek-v4-pro[1m]
export ANTHROPIC_DEFAULT_OPUS_MODEL=deepseek-v4-pro[1m]
export ANTHROPIC_DEFAULT_SONNET_MODEL=deepseek-v4-pro[1m]
export ANTHROPIC_DEFAULT_HAIKU_MODEL=deepseek-v4-flash
export CLAUDE_CODE_SUBAGENT_MODEL=deepseek-v4-flash
export CLAUDE_CODE_EFFORT_LEVEL=max

模型映射规则：

  • claude-opus → deepseek-v4-pro

  • claude-sonnet → deepseek-v4-flash

  • claude-haiku → deepseek-v4-flash

附录：.zshrc_sample（四平台并集）

四个平台的全量参数取并集。切换平台时只需改 ANTHROPIC_AUTH_TOKEN 和 ANTHROPIC_BASE_URL，其余模型变量全部保留（Claude Code 自动按 ANTHROPIC_BASE_URL 路由，多余变量无副作用）。

# ============================================================
# Claude Code — 第三方平台配置（DeepSeek / GLM / LongCat / MiniMax 并集）
# 来源：各平台官方文档（2026.07）
# 使用方法：替换下方 API Key、BASE_URL 和模型名称，source ~/.zshrc 生效
# 模型说明：<主力模型> = 该平台最强款，<轻量模型> = 该平台最速/最廉款
# ============================================================


# ── 必填：切换平台时只改这两个 ──
export ANTHROPIC_AUTH_TOKEN="<你的 API Key>"
export ANTHROPIC_BASE_URL="<平台 Anthropic 兼容地址>"


# ── 模型映射（pro 模型用最强款，flash 模型用最速/最廉款） ──
export ANTHROPIC_MODEL="<主力模型>"
export ANTHROPIC_DEFAULT_OPUS_MODEL="<主力模型>"
export ANTHROPIC_DEFAULT_SONNET_MODEL="<主力模型>"
export ANTHROPIC_DEFAULT_HAIKU_MODEL="<轻量模型>"
export CLAUDE_CODE_SUBAGENT_MODEL="<轻量模型>"
export ANTHROPIC_SMALL_FAST_MODEL="<轻量模型>"


# ── 行为调优（四平台并集） ──
export CLAUDE_CODE_EFFORT_LEVEL=max
export CLAUDE_CODE_AUTO_COMPACT_WINDOW="1000000"
export CLAUDE_CODE_MAX_OUTPUT_TOKENS="131072"
export CLAUDE_CODE_DISABLE_NONESSENTIAL_TRAFFIC=1
export CLAUDE_CODE_DISABLE_NONSTREAMING_FALLBACK=1
export CLAUDE_CODE_DISABLE_EXPERIMENTAL_BETAS=1
export API_TIMEOUT_MS="3000000"
